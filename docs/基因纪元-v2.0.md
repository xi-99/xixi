# 🧬 WORLD3 v2.0 基因纪元 —— 设计与实验指南

> 目标只有一个：把 Agent 的"大脑"从程序员写的 if-else，替换成能自我进化的**数字基因**。
> 这一版不再回答"什么参数最有效"，而是回答：**生命能否无中生有地学会生存？**

## 0. 为什么是 v2.0

v1.0 的核心旋钮是"犹豫概率"——Agent 的觅食逻辑全部由手写的规则（决心机制）决定，
调参只是在"预设的行为菜单"里挑选项。评论者指出的"基因缺位"一针见血：

> 没有遗传与变异，就没有真正的演化；没有演化的模拟，只是参数搜索。

v2.0 把决策权从规则交给权重，把优化权从滑条交给自然选择：

| 维度 | v1.0（当前） | v2.0（目标） |
|---|---|---|
| 决策方式 | 硬编码 if-else（决心机制） | 感知机神经网络（随机权重产生的本能） |
| "智能"来源 | 手动调参（滑条调优） | 遗传算法（自然选择 + 随机变异） |
| 行为边界 | 锁死在预设的行为菜单里 | 开放（理论上能涌现出从未写过的策略） |
| 实验意义 | 验证"什么参数最有效" | 验证"生命能否无中生有地学会生存" |

## 1. 架构总览（微内核视角）

v2.0 遵循项目既有的微内核 + 插件架构，改动落点：

```
app.py（Streamlit 控制台）
  └─ 🧬 Agent 模式开关：硬编码（对照组）↔ 进化模式（实验组）
world_engine.py（微内核）
  ├─ _new_agent：进化模式下初代 prey 出生即携带随机基因
  ├─ _tick_once：每 generation_ticks 触发 evolution.turnover（世代更替）
  └─ stats()：新增 generation（当前世代数）
evolution.py（新增 · 数字基因核心）
  ├─ 感知机：forward / softmax / sample_move
  ├─ 基因组：random_genome（随机本能）/ crossover（单点交叉）/ mutate（高斯变异）
  └─ 自然选择：fitness（本世代适应度）/ turnover（全员换代）
plugins/gene_brain.py（新增 · 基因大脑插件）
  └─ 感知 4 标量 → 采样动作 → 移动（零规则，行为全在权重里）
plugins/focus.py（保留 · 硬编码对照组大脑）
plugins/metabolism.py（保留 · 进食/代谢/死亡，两套大脑共用）
```

> 说明：计划书提到"修改 agent.py 删除 if-else"。在微内核架构下，
> v1 大脑实际位于 plugins/focus.py（Web 控制台路径），
> agent.py / world.py 是命令行引擎（main.py/tune.py）的遗留实现，不在本次改动范围。

## 2. 数字基因：感知机

### 2.1 感知输入（4 维）

每个 Agent 每 tick 感知 4 个标量：

| 分量 | 含义 | 范围 |
|---|---|---|
| x0 | 最近食物距离 ÷ 视野（视野内无食物 = 1.0） | [0, 1] |
| x1 | 最近食物的 sin 分量（环形最短路径 x 偏移 ÷ 视野） | [-1, 1] |
| x2 | 最近食物的 cos 分量（环形最短路径 y 偏移 ÷ 视野） | [-1, 1] |
| x3 | 当前能量 ÷ 300（ENERGY_SCALE） | [0, 1] |

> 计划书写"输入层 3 节点（距离、方向 sin/cos、能量）"，实际是 4 个标量。
> 方向以归一化分量（dx/视野、dy/视野）而非纯角度实现——对单层感知机而言，
> "朝食物走"（logit ∝ dx）是线性可学的；若喂纯角度则需要乘积项，线性网络学不到。

### 2.2 输出动作（5 个）

| 输出 | 动作 |
|---|---|
| 0/1/2/3 | 上 / 下 / 左 / 右 |
| 4 | **驻留**（站在食物上细嚼慢咽） |

> 计划书为 4 节点。我们把"驻留"加入动作空间：没有驻留，Agent 永远无法
> "停在食物上进食"，觅食只能学到乱跑。仍是纯感知机，只是动作空间更完整。
> 输出经 softmax 变成概率，用世界随机数采样——同样的基因，行为也有随机性。

### 2.3 基因组

单层感知机：W(4×5) + b(5) = 25 个浮点数，出生时 U(-1,1) 均匀随机。
**行为完全由这 25 个数决定，代码里没有一条觅食规则。**

## 3. 进化引擎：自然选择

### 3.1 适应度（计划书公式）

```
适应度 = 本世代存活时间 × 本世代进食数量
```

- 存活时间 = 出生（或上次世代更替）到当前 tick / 死亡 tick；
- 进食数量 = eaten − eaten_base（每次更替时全员重置基数，**每代同一起跑线**）；
- 没吃到任何食物 → 适应度 0 → 基因出局："饿死的个体没有后代"。

### 3.2 世代更替（每 generation_ticks tick，默认 5000）

全员换代（对应计划书："选择适应度前 20% 作为父母 → 交叉 → 变异 → 子代填充种群"）：

1. **排名**：活体 prey 按本世代适应度排序；
2. **父母**：前 elite_fraction（默认 20%）；
3. **全员退休**：所有个体能量归还脚下网格（守恒）；
4. **子代**：填满种群（agent_count 只），每只由两名随机父母的基因
   **单点交叉**（交换基因片段）→ **高斯变异**（每个基因加 N(0, σ) 噪声，σ 默认 0.15）；
5. **出生能量**：从出生地（随机位置）周围 9 格实地采集，最多 init_energy——
   只取存在的能量、绝不创造；出生在富饶之地的孩子天生更有能量，这是空间选择压力。

### 3.3 能量守恒（严格成立）

- 退休：网格[脚下] += 能量；能量 = 0；
- 出生：网格 -= 实际采到的量；子代 += 同量（只减不增，取不到就少给）。

两步都是"能量搬家"，因此"网格总和 + 活体能量总和"恒等于初始总量。
引擎每 500 tick 审计，v2.0 实测守恒偏差 ~1e-9、审计 0 失败。

### 3.4 与计划书的三处差异（已论证）

| 计划书 | 实现 | 理由 |
|---|---|---|
| 精英保留 | 全员换代 | 精英制下初代 8 只会因"资历+能量囤积"永久霸榜（实测 max_gen 卡死=1），基因池永不轮换；全员换代才能让进化滚动（实测世代逐代递增） |
| 子代继承父母能量 | 环境出资（就地采集） | 父母均摊后每个孩子仅 ~37 能量，在食物分散的世界里活不到下一世代更替；环境出资让孩子带满额能量出生，且"出生地富饶度"本身成为选择压力 |
| 4 输出 | 5 输出（+驻留） | 无驻留则"停在食物上吃"不可学，见 §2.2 |

## 4. 对照实验：死规则 vs 活基因（最强证据）

在右侧控制面板 **🧬 Agent 模式** 切换：

1. **硬编码（对照组）**：v1 决心机制，if-else 规则；
2. **进化模式（实验组）**：基因大脑 + 自然选择。

**同样的世界规则（能量、地图、种子），唯一变量是"大脑来源"。**

推荐流程（同种子公平对比）：

1. 记录种子（如 42），Agent 模式选**硬编码**，重复次数 3，点击开始；
2. 记下平均存活率与最终曲线；
3. Agent 模式切到**进化模式**，同一种子再跑 3 次；
4. 对比：
   - **存活率曲线**：进化模式种群恒定满员（世代更替不断补充），
     硬编码种群单调衰减——进化模式"续命"的能力一目了然；
   - **🧬 进化趋势图**（批次结果下方新增）：父母本代进食量逐代变化。
     上升 = 基因在适应世界；这是"自然选择真的在工作"的直接证据；
   - **世代计数**：状态栏显示当前世代，初代蓝点（随机本能）vs 后代金点（进化产物）。

### 观察现象（供验证，具体数值随种子浮动）

- **绿洲税**：第 1 代父母进食量往往最高（初代赶上完整绿洲）；
  第 2 代跌至 ~65%，随后逐代缓慢回升——环境劣化快于进化的初期，进化在追。
- **出生地彩票**：总会有少量子代出生在贫瘠地（采集不足），幼年夭折属正常淘汰。
- 参数旋钮：**变异强度 σ** 越大探索越强（实测 σ=0.2 回升最快）、
  世代间隔越小轮换越快、精英比例越大基因池越保守。
