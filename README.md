# WORLD3 —— 数字生命沙盒实验平台

> 「人的本质，无非就是一堆非常简单的东西，堆到一起，然后涌现出这么复杂的人类。」
>
> WORLD3 让你亲眼看着 100 个只有几条 if-else 的「傻瓜」，在能量守恒的二维网格世界里挣扎、觅食、繁衍、被捕食——然后亲手回答一个问题：**「决心」，是不是它们活下来的关键？**

## 项目简介

WORLD3 是一个基于 Streamlit 的多智能体（Multi-Agent）演化模拟平台。

- 每个 Agent 只有几条简单的决策规则：感知 → 打分 → 决策 → 执行；
- 复杂行为（代谢、决心、捕食）全部以**插件**形式提供，可随时启停、热刷新；
- 世界严格遵循**能量守恒**：能量只搬家，不消失，也不凭空出现，每 500 tick 自动审计；
- 内置**参数调优**（滑条 + 扫描）、**历史记录与复现**（SQLite）、**自动诊断报告**、**挂机实验**，开箱即用。

## 核心功能

| 功能 | 说明 |
|---|---|
| 🗺️ 实时 2D 地图 | 能量点、绿色 Agent、红色捕食者同屏演化；可关闭动画省 CPU，后台实验照常运行 |
| 🎚️ 参数滑条 | 全部世界参数滑条化（滑条 + 数字输入），悬停即见解释，实验运行中自动锁定 |
| 🧩 插件系统 | 代谢 / 决心 / 捕食者三大预置插件；侧边栏一键启停，支持运行时热扫描新插件 |
| 📜 历史记录与复现 | 每次实验自动写入 SQLite；点击编号查看详情（曲线 + 分段复盘 + 参数），一键复制参数重新运行 |
| 🔍 自动诊断报告 | 实验结束自动生成：终止原因 + 宏观结论 + 四段分段复盘 |
| 📈 参数扫描 | 单参数顺序扫描或随机扰动，散点图 + 趋势线 + 最优参数绿色高亮 |
| 🤖 挂机实验 | 实验在后台线程运行，关闭浏览器标签页也会继续跑完并落库 |

## 快速开始

1. **克隆仓库**

   ```bash
   git clone https://github.com/xi-99/WORLD3.git
   cd WORLD3
   ```

2. **安装依赖**（需要 Python 3.9+）

   ```bash
   pip install -r requirements.txt
   ```

3. **启动**

   - Windows：双击 `start.bat`
   - Linux / macOS：`./start.sh`
   - 或手动执行：`streamlit run app.py`

4. **打开浏览器**

   访问 http://localhost:8501 ，点击「开始」即可观察世界演化。

> 提示：若 8501 端口被占用，请先关闭旧的 Streamlit 进程再启动。

## 实验示例：决心概率的「犹豫税」

「决心概率」（distract_prob）是 WORLD3 最有趣的旋钮：它决定 Agent 锁定目标后会不会中途变卦。

1. 在右侧参数区把 **决心概率** 设为 `0.0`（决心型：死磕到底），重复次数设为 `3`，点击「开始」；
2. 等待实验结束，记录平均存活率；
3. 把 **决心概率** 改为 `0.8`（犹豫型：每步都重新思考），同一种子再跑 3 次；
4. 对比两条叠加曲线的终点：**决心型种群往往能稳定存活，犹豫型种群更容易崩溃**——每步都「重新想想」的 Agent 会在犹豫中耗尽能量，这就是「犹豫税」。

> 具体存活率数值取决于随机种子与世界参数（食物密度、捕食者数量等），实际以你的运行结果为准。可以在「自动调参扫描」模式下扫描 `distract_prob`，观察存活率随犹豫程度的相变曲线。

## 插件扩展

WORLD3 采用微内核 + 插件架构，添加新插件只需要四步：

1. 在 `plugins/` 目录下新建一个 Python 文件，例如 `plugins/my_plugin.py`；
2. 按需实现以下四个接口函数（缺失的会自动空操作兜底，不会崩溃）：

   ```python
   # plugins/my_plugin.py

   def register(world):
       """可选：插件初始化，world 为世界内核对象"""
       pass

   def on_tick(agents, grid):
       """必选：每 tick 的行为逻辑。agents 是 Agent 字典列表，
       grid[y, x] 读写能量，grid.world 可取内核工具（移动/距离/散落）"""
       pass

   def on_render(ax, agents, grid):
       """可选：在地图上叠加自定义图形（ax 为 matplotlib 坐标轴）"""
       pass

   def ui_controls(world):
       """可选：专属控制控件（默认由 app.py 统一渲染参数滑条）"""
       pass
   ```

3. 在侧边栏「🧩 插件管理」中点击 **🔄 刷新插件列表**；
4. 打开新插件的启用开关，重新开始实验即可生效。

插件内抛出的异常不会打崩世界——对应插件会被自动禁用并记录到死亡明细中。

## 技术栈

- **Python 3.9+**
- **Streamlit** —— Web 控制台与实时渲染
- **NumPy** —— 网格与随机性
- **Matplotlib** —— 2D 地图与结果图表
- **SQLite**（标准库 `sqlite3`）—— 实验历史存储
- **pandas** —— 多曲线结果聚合
- zstandard（可选）—— 仅 `token_stats.py` 用量统计工具使用
